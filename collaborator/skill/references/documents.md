# Document collaboration

Use the project's Documents area on cmd.zeuglab.com as the current agreement
record. Read the current version and its outstanding comments before drafting
a change. Keep suggested wording separate from the accepted document.

Use the connected document tools only when they are advertised and permit the
requested operation; otherwise prepare the suggestion and open the relevant
document in CMD. Do not invent an API or claim a document was changed because
you wrote a draft locally. Never overwrite another person's suggestion.

The document owner accepts or declines suggestions. Accepted edits create a
new version; approvals must apply to that same version. Record decisions in
Linear or shared memory with the document link and version. Reading,
suggesting, approving and signing are separate actions. The collaborator
reviews legal commitments and signs personally; installation or project
membership never authorizes an AI to sign.
